# Mountain Coffee 3D · TAU ROAST

Демо-лендинг выдуманного кофейного бренда **TAU ROAST**: горная арабика, обжаренная в Алматы.
3D-банка и кофейные зёрна двигаются при прокрутке, как на лендингах товаров из рилсов.

> Демо-сайт для портфолио. Бренд выдуман, форма заявки никуда не отправляет данные.

## Что внутри

- **3D-банка** с этикеткой, нарисованной кодом (`drawLabel()`), латунной крышкой и дном
- **Кофейные зёрна** с плоской стороной и изогнутой бороздкой (`beanGeometry()`)
- **Невидимая фотостудия** с софтбоксами для отражений (`softbox()`) и тональная коррекция ACES
- **Сценарий прокрутки**: банка справа → слева с оборотом → по центру → улетает вверх (`poses`, `state`)
- Отдельная раскладка для телефона, режим «уменьшить анимацию», запасной вариант без 3D

## Технологии

Один файл `index.html` · [Three.js r128](https://threejs.org/) · [GSAP 3.12 + ScrollTrigger](https://gsap.com/) · шрифты Oswald, Marck Script, Manrope, JetBrains Mono

## Как запустить

Откройте `index.html` в браузере. Сборка и установка не нужны.

## Как переделать под другой бренд

| Что поменять | Где |
|---|---|
| Этикетка банки | функция `drawLabel()` |
| Цвета | блок `:root` в CSS |
| Тексты | разметка HTML |
| Положения банки на экранах | объект `poses` |
